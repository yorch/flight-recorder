## What it is

An AI agent drives a real, headful, sandboxed Chrome inside Docker to execute a browser test — either a
recorded `TestSpec` or a plain-English goal it first turns into a plan. Everything it sees and does is
recorded, and the pass/fail verdict is decided by the harness from deterministic evidence, never by the
agent's own claim.

<CardGrid>
  <Card title="Evidence, not vibes" icon="document">
    Screen video with idle time compressed, an event timeline, screenshots, the model transcript and a
    per-request network log — all time-synchronised in one run directory.
  </Card>
  <Card title="Harness verdict" icon="approve-check">
    Assertions the harness executes plus an evaluator that can only *downgrade* a run. The agent claiming
    success is never enough.
  </Card>
  <Card title="Isolation by construction" icon="lock">
    The run pair shares a network namespace with no route out; all egress goes through an allowlisting
    Squid proxy, and the browser keeps its sandbox on.
  </Card>
  <Card title="Reviewable plans" icon="list-format">
    Natural-language runs plan first, optionally wait for approval, then execute step by step with
    chapters marked `pN · label` in the video.
  </Card>
